## Sobre mim

Sou desenvolvedor de software com foco em **Front-end, aplicações Full Stack e experiências digitais interativas**.

Tenho experiência profissional no desenvolvimento de aplicações web, construção de interfaces responsivas, integração de APIs REST e implementação de funcionalidades utilizando tecnologias como **TypeScript, React, Svelte, NestJS e PostgreSQL**.

Gosto de trabalhar na interseção entre **engenharia de software e design**, desenvolvendo soluções que combinam organização, desempenho, usabilidade e identidade visual.

Estou concluindo a graduação em **Ciência da Computação no Centro Universitário de Brasília (CEUB)**, com previsão de conclusão em 2026.

Atualmente, dedico parte do meu tempo ao desenvolvimento de produtos próprios, aprimoramento das minhas habilidades Full Stack e exploração de novas experiências para a web.

## Projetos em Destaque

### 01 / Vem Comigo — Portal Institucional

Plataforma web desenvolvida para um projeto educacional voltado à convivência ética, à prevenção do bullying e à melhoria do clima escolar.

Atuei no desenvolvimento Front-end, UI/UX e gerenciamento do projeto, trabalhando na criação de uma experiência acessível, responsiva e interativa.

**Stack:** React · TypeScript · Tailwind CSS

[Acessar projeto](https://vemcomigo.vercel.app)

### 02 / FlowBoard — Project Management Platform

Aplicação Full Stack de gerenciamento de projetos e tarefas, desenvolvida com foco em organização, produtividade e experiência de uso.

O projeto reúne autenticação, gerenciamento de projetos, quadro Kanban interativo, persistência de dados e dashboard, com evolução para funcionalidades colaborativas.

**Stack:** Next.js · TypeScript · PostgreSQL · Prisma

*Projeto em evolução.*

### 03 / Digital Lab — Personal Portfolio

Portfólio pessoal desenvolvido como uma experiência digital interativa, explorando a relação entre desenvolvimento web, design e tecnologias gráficas.

O projeto utiliza animações avançadas, efeitos de partículas, interações com o cursor e transições baseadas em scroll para apresentar meus trabalhos de maneira mais expressiva.

**Stack:** React · Next.js · TypeScript · Tailwind CSS · GSAP · WebGL

[Repositório](https://github.com/PedroDelgo/portfolio)
